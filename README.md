# 🎭 Emotion-Based Movie Recommendation System

This project uses real-time facial emotion detection to recommend movies based on your mood. Built with DeepFace, TMDB API, and a modern frontend interface.

## 💡 Features

- 🎥 Detects emotions from webcam or uploaded image
- 🤖 Uses DeepFace for facial emotion recognition
- 📽️ Recommends movies from TMDB based on emotion
- ⚡ Fast and mobile-responsive frontend
- 🔐 Config and sensitive keys hidden for security

## 🧠 Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** FastAPI
- **AI/ML:** DeepFace(Emotion Detection)
- **API:** TMDB (The Movie Database)
- **Tools:** Python, Node.js, Git
